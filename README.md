# Star Processing & Compliance Services

Marketing website for [Star Processing & Compliance Services](https://www.star-processing.com), a mortgage processing and compliance company founded by Stephenie Tocado, serving loan officers and brokers in North Carolina and South Carolina.

## Stack

Static HTML, CSS, and vanilla JavaScript — no build step required. Just open `index.html` in a browser, or deploy the folder to any static host (Netlify, Vercel, GitHub Pages, Cloudflare Pages, S3, etc.).

## Pages

- `index.html` — homepage with hero, founder section, services snapshot, how-it-works, "more than processing", FAQ, and CTAs
- `services.html` — detailed services breakdown
- `about.html` — Stephenie's story and values
- `pricing.html` — transparent per-file pricing
- `contact.html` — contact form and details

## Assets

- `styles.css` — design system + component styles
- `script.js` — nav scroll behavior, mobile menu, reveal animations, FAQ toggle, form mailto handler
- `1.png` — full Star Processing logomark
- `2.png` — star icon mark
- `Professional portrait with a warm smile.png` — Stephenie's portrait

## SEO & AI search

The homepage includes:

- `ProfessionalService` / LocalBusiness JSON-LD schema (NMLS, address, founder, area served, services)
- `FAQPage` JSON-LD schema with 30+ Q&As covering general loan-officer queries, local "near me" / "best in NC/SC" / city-specific searches
- Open Graph and Twitter card meta tags
- Canonical URL and structured keyword meta
